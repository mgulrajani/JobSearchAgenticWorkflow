AI-Powered Course Generator
An AI-powered curriculum design assistant built using n8n and Ollama.

The system helps trainers, instructional designers, learning consultants, and training organisations rapidly generate complete training programmes from a simple set of inputs.

Overview
Designing training programmes often involves repetitive work such as:

Writing learning objectives
Creating agendas
Designing activities
Building assessments
Drafting quizzes
This workflow automates these tasks and produces structured training content within minutes.
